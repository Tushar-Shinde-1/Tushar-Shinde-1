# 🧠 Featured Work

## 🌱 AI-Powered Seed Quality & Germination Prediction

**Computer Vision • Deep Learning • Multimodal ML • PyTorch • YOLOv8 • XGBoost • OpenCV**

Built a multimodal AI system combining image features with sensor data to predict seed germination probability, viability classes, and quality grades.

**Highlights**

* Fine-tuned YOLOv8 on **6,500+ annotated seeds**
* Combined **ResNet-18 image features with moisture and weight data**
* Integrated XGBoost for tabular/sensor information
* Used OpenCV for morphology and surface-defect analysis
* Achieved **~3.8% germination prediction error**
* Achieved **88%+ classification accuracy**
* Reduced evaluation time from **7–14 days to <1 second**
